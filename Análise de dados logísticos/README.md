# Análise Exploratória de Dados Logísticos - Loggi  

Este projeto visa explorar e analisar dados logísticos da empresa **Loggi**, com foco na distribuição de entregas em relação aos centros de distribuição do Distrito Federal. O principal objetivo foi identificar padrões, tendências e gargalos nas operações logísticas, com um desafio adicional relacionado ao uso de dados de geolocalização.  

---

## Habilidades Utilizadas  

- **Python**:  
  - *Pandas* e *NumPy*: Manipulação e análise de grandes volumes de dados.  
- **Visualização de Dados**:  
  - *Matplotlib* e *Seaborn*: Criação de gráficos e dashboards para identificação de tendências e anomalias.  
- **Análise Estatística**:  
  - Cálculo de métricas relevantes e uso de técnicas descritivas para compreender o comportamento dos dados.  

---

## Insights  
### Principais Descobertas  
1. **Distribuição de Entregas por Região**:  
   - As regiões **DF-1** e **DF-2** concentram a maior parte das entregas, com seus centros de distribuição localizados próximos às áreas de maior demanda.  
   - A região **DF-0** apresenta um volume menor de entregas, porém estas são caracterizadas por trajetos mais longos e demorados.  

2. **Tamanho das Entregas**:  
   - Os tamanhos das entregas se mostram equilibrados entre os diferentes hubs, com proporções consistentes para todas as regiões.  

### Proposta de Solução  
- Criar hubs menores em áreas afastadas dos centros de distribuição principais, o que reduziria as distâncias das entregas e aumentaria a eficiência logística.
