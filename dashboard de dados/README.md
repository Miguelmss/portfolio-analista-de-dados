# Dashboard Interativo sobre a Pandemia de COVID-19  

Este projeto desenvolveu um **dashboard interativo** focado em acompanhar a evolução dos casos, mortes e progressão da vacinação durante o ano de **2022**. A proposta foi criar uma ferramenta visual e informativa que permitisse análises claras e acessíveis tanto para o público geral quanto para profissionais de saúde, ajudando a identificar padrões e tendências relevantes da pandemia.  

---

## Passo a Passo do Projeto  

1. **Coleta de Dados**:  
   - Os dados foram obtidos de fontes confiáveis, incluindo as universidades **Johns Hopkins** e **Oxford**.  

2. **Processamento dos Dados**:  
   - Tratamento de inconsistências e redimensionamento.  
   - Padronização das informações.  
   - Criação de novas variáveis para enriquecer as análises.  

3. **Criação do Dashboard**:  
   - Uso de ferramentas de visualização para gráficos interativos, incluindo:  
     - Linhas do tempo para evolução de casos e mortes.  
     - Mapas de calor para a distribuição geográfica dos dados.  

4. **Análise dos Resultados**:  
   - Identificação de picos de casos e mortes ao longo do tempo.  
   - Análise da correlação entre o avanço da vacinação e a redução no número de mortes.
