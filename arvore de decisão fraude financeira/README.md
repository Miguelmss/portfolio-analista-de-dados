# Detecção de Fraudes Financeiras  

Este projeto teve como objetivo identificar fraudes financeiras utilizando algoritmos de aprendizado de máquina. O processo envolveu desde a análise exploratória de dados até a modelagem preditiva. 
---

## Passo a Passo do Projeto  

1. **Exploração de Dados**:  
   - Análise detalhada do conjunto de dados financeiros para identificar padrões e características associadas a fraudes.  

2. **Preparação dos Dados**:  
   - Tratamento de valores ausentes, normalização das variáveis e preparação do dataset para os modelos de aprendizado de máquina.  

3. **Construção de Modelos**:  
   - Desenvolvimento e avaliação de modelos de machine learning, incluindo ajuste de hiperparâmetros para maximizar a performance.  

4. **Visualizações**:  
   - Criação de gráficos para compreender a distribuição dos dados e interpretar os resultados do modelo.  

---

## Insights Identificados  

- **Padrões de Fraude**: Identificação de características recorrentes em transações fraudulentas, permitindo melhor classificação pelos modelos.  
- **Impacto do Pré-processamento**: Melhorias significativas na performance dos modelos após o tratamento e normalização dos dados.  

---

## Habilidades Utilizadas  

- **Python**: Manipulação de dados com **Pandas** e **NumPy**.  
- **Machine Learning**: Modelagem com **Scikit-learn**, incluindo algoritmos como árvores de decisão e regressão logística.  
- **Visualização de Dados**: Utilização de bibliotecas como **Matplotlib** e **Seaborn** para análise gráfica.
