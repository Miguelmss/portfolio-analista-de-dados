# Análise de Dados de Crédito Bancário  

Este projeto teve como foco a **análise de dados de crédito bancário** de mais de 10 mil indivíduos. Utilizamos a linguagem **SQL**, uma ferramenta essencial para manipulação e consulta de dados, com o objetivo principal de explorar os dados, propor sugestões de melhorias para o banco e aprimorar o domínio da linguagem SQL em um cenário prático.  

---

## Passo a Passo do Projeto  

1. **Coleta de Dados**:  
   - Os dados foram obtidos através de informações fornecidas pela **EBAC**.  

2. **Criação de Perguntas de Pesquisa**:  
   - Elaboração de questões a serem respondidas por meio de consultas SQL no **AWS Athena**.  

3. **Execução de Queries e Storytelling**:  
   - Realização das consultas SQL.  
   - Criação de um notebook no **Kaggle**, incluindo:  
     - Análise dos dados.  
     - Apresentação dos resultados das queries.  
     - Insights e recomendações baseadas nos dados analisados.  

---

## Insights Identificados  

- **Idade Média dos Clientes**: A média de idade é de **40 anos**, indicando um público mais maduro.  
- **Limite de Crédito por Gênero**: Homens têm um limite de crédito **240% maior** que o das mulheres.  
- **Faixa Salarial**: A maioria dos clientes ganha menos de **40k anuais**, o que sugere um público com renda predominantemente baixa.  
- **Valores Nulos**: Registros nulos em escolaridade e salário anual precisam ser corrigidos para melhorar a qualidade da análise.
